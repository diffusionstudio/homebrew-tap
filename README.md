# Diffusion Studio Homebrew Tap

Install [Diffusion Studio](https://diffusion.studio/):

```bash
brew install --cask diffusionstudio/tap/editor
```

The app updates itself; `brew upgrade` intentionally skips it. To force a
reinstall through Homebrew, run `brew reinstall --cask editor`.

The cask version is bumped automatically by CI in
[diffusionstudio/editor](https://github.com/diffusionstudio/editor) when a
release is published.
